일본어 회화 노선도

유닛 하나가 회화 한 번입니다. 단어와 문법을 먼저 연습하고 대화를 시작합니다. 주황색 역에서 새 문법이 나옵니다.

매일 과정 (하루 15분) →듀오링고 없이 카드 한 장씩

내 섹션

프로젝트 세팅 (한 번만)

  1. Claude 앱이나 휴대폰 브라우저의 claude.ai에서 새 프로젝트 「일본어 회화」를 만듭니다.
  2. 지침 복사를 눌러 프로젝트 지침에 붙여 넣습니다.
  3. 유닛 자료 복사를 눌러 프로젝트 지식의 + 버튼으로 넣습니다.
  4. 프로젝트 안 새 대화에 세팅이라고 입력해 되는 것을 확인합니다.
  5. 휴대폰 앱의 음성 설정에서 언어를 일본어로, 속도를 느리게 고릅니다.

섹션 추가

프로젝트는 그대로 둡니다. 맨 위에서 섹션을 고르고 유닛 자료 복사를 눌러 프로젝트 지식에 하나 더 넣습니다. 단어장도 이어집니다. 2026년 11월 3일 전에 세팅했다면 지침 복사로 지침을 한 번 다시 붙입니다.

회화 시작

  1. 프로젝트 안에서 새 대화를 열고 유닛 번호를 입력합니다.
  2. 준비됐다는 답이 오면 음성 버튼을 누르고 일본어로 바꿔 주세요라고 말합니다.
  3. 바뀌면 はじめましょう나 시작이라고 말합니다.
  4. 끝나면 음성을 끄고 정리라고 입력합니다. 틀린 내용과 단어가 메모리에 저장됩니다.

말로 바뀌지 않으면 음성 설정에서 일본어를 고릅니다.

복습

유닛 다섯 개를 마칠 때마다 복습 세트가 열립니다. 새 대화에서 유닛 번호 대신 복습이라고 입력하면, 그동안 배운 유닛에서 무작위로 고른 문장 여섯 개와 회화 하나를 연습합니다. 진도는 바뀌지 않습니다.

복습 세트가 들어가기 전(2026년 11월 14일)에 세팅했다면 지침 칸을 지우고 새 지침을 붙입니다. 프로젝트 지식의 예전 유닛 자료 파일은 지우고, 유닛 자료를 새로 복사해 넣습니다. 메모리와 단어장은 그대로 이어집니다.

노선

프로젝트 안 새 대화에 번호만 입력합니다. 다음 번호는 비워 두면 튜터가 이어 갑니다. 다른 섹션으로 옮길 때는 섹션 2 유닛 1처럼 입력합니다.

    매일 과정 (하루 15분)

    듀오링고와 상관없이 혼자 하는 과정입니다. 카드 한 장이 하루 수업이고, 복습과 새 단어, 회화, 마지막 확인을 한 번에 합니다. 다음 카드로 넘어갈지는 튜터가 정합니다. 1단계는 카드 30장입니다.

    1. 새 프로젝트 「일본어 매일」을 만듭니다. 위의 「일본어 회화」 프로젝트와 따로 둡니다.
    2. 매일 지침 복사를 눌러 프로젝트 지침에 붙여 넣습니다.
    3. 1단계 자료 복사를 눌러 프로젝트 파일에 텍스트로 넣습니다. 붙여 넣기가 안 되면 1단계 자료 파일 받기로 받은 파일을 넣습니다.
    4. 프로젝트 안 새 대화에 세팅이라고 입력합니다. 카드 1 제목이 나오면 준비가 끝났습니다.
    5. 매일 새 대화를 열고 음성 버튼을 누른 뒤 시작이라고 말합니다. 끝나면 음성을 끄고 정리라고 입력합니다.
    듀오링고와 관계없는 개인이 만든 비공식 자료입니다. 문장은 직접 지었고 듀오링고의 문장, 단어 목록, 로고를 쓰지 않습니다. Duolingo는 Duolingo, Inc.의 상표입니다.
