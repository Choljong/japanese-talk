듀오링고 일본어 섹션 1~3에 맞춘 비공식 회화 연습

일본어 회화 노선도

유닛 하나가 회화 한 번입니다. 단어와 문법을 먼저 연습하고 대화를 시작합니다. 주황색 역에서 새 문법이 나옵니다.

내 섹션

프로젝트 세팅 (한 번만)

  1. Claude 앱이나 휴대폰 브라우저의 claude.ai에서 새 프로젝트 「일본어 회화」를 만듭니다.
  2. 지침 복사를 눌러 프로젝트 지침에 붙여 넣습니다.
  3. 유닛 자료 복사를 눌러 프로젝트 지식의 + 버튼으로 넣습니다.
  4. 프로젝트 안 새 대화에 세팅이라고 입력해 되는 것을 확인합니다.
  5. 휴대폰 앱의 음성 설정에서 언어를 일본어로, 속도를 느리게 고릅니다.

섹션 추가

프로젝트는 그대로 둡니다. 맨 위에서 섹션을 고르고 유닛 자료 복사를 눌러 프로젝트 지식에 하나 더 넣습니다. 단어장도 이어집니다. 2026년 11월 3일 전에 세팅했다면 지침 복사로 지침을 한 번 다시 붙입니다.

회화 시작

  1. 프로젝트 안에서 새 대화를 열고 유닛 번호를 입력합니다.
  2. 준비됐다는 답이 오면 음성 버튼을 누르고 일본어로 바꿔 주세요라고 말합니다.
  3. 바뀌면 はじめましょう나 시작이라고 말합니다.
  4. 끝나면 음성을 끄고 정리라고 입력합니다. 틀린 내용과 단어가 메모리에 저장됩니다.

말로 바뀌지 않으면 음성 설정에서 일본어를 고릅니다.

이렇게 말합니다

한국어로 다시, 천천히, 힌트, 모르겠어요, 다음, 끝처럼 말해도 됩니다.

  • もう一度 다시 천천히
  • ゆっくり 계속 더 천천히
  • ヒント 첫 글자 힌트
  • わかりません 뜻 설명
  • 覚えて 단어장에 넣기
  • 単語帳 단어 읽어 주기
  • クイズ 단어 퀴즈
  • つぎ 다음으로
  • おわりましょう 마무리

노선

프로젝트 안 새 대화에 번호만 입력합니다. 다음 번호는 비워 두면 튜터가 이어 갑니다. 다른 섹션으로 옮길 때는 섹션 2 유닛 1처럼 입력합니다.
